# SPDX software bill of materials

`nysos.spdx.json` is an SPDX 2.3 JSON inventory generated by the Nix-pinned
`cargo-sbom` and validated by the uv-pinned SPDX Python tools.

```sh
nix develop
make sbom          # Fetch locked crates, regenerate and validate
make sbom-check    # Validate schema, dependency coverage, license/version and lock digest
```

The inventory includes nysos and its transitive normal/build Cargo dependencies
across platforms. It excludes development-only crates, the Nix build toolchain,
Python documentation tooling, system libraries, and analysis of compiled binaries.
It is a source dependency inventory, not an OS or final-binary SBOM.

Crate archive SHA-256 values come from `Cargo.lock`; licenses come from Cargo
package declarations. `licenseConcluded` and third-party copyright are
`NOASSERTION`, since metadata alone does not establish legal conclusions or
copyright ownership. Dependency licenses remain their own; Apache-2.0 applies to
nysos's first-party code. SPDX document metadata uses the required CC0-1.0 data
license.

The checked-in snapshot is regenerated for dependency/license changes and on
release PRs. CI uploads a fresh `nysos-spdx-sbom` artifact; Release Please's
workflow attaches the release-specific SBOM to published GitHub releases.
Creation times and document namespaces change with each generation.
