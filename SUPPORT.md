# Getting help

Start with the [user documentation](docs/index.md),
[configuration reference](docs/reference/configuration.md), and
[troubleshooting guide](docs/guide/troubleshooting.md).

For bugs and feature requests, use [GitHub issues](https://github.com/McCodeman/nysos/issues).
Include `nysos --version-full`, OS, terminal, whether tmux or SSH is involved,
expected and actual behavior, and a minimal reproduction. Remove secrets.

Report security vulnerabilities privately using [SECURITY.md](SECURITY.md).
